# Changelog

Indexed/normalized CPU WFA; checkpointed exact traceback; threaded batches and deadlines; adaptive heuristic retries; strict backend requests; experimental CUDA batching and Python dispatch with mixed-backend metadata; disk-indexed mapper inputs; persistent cancellable Studio jobs; global search, streamed exports, demo jobs and redesigned light/dark UI; indexed variant navigation; portable frontend lockfile and bundled wheels; expanded benchmarks, CI and workflow examples.
