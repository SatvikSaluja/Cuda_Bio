# Security

WarpAlign is research software, not clinically validated. Studio is an unauthenticated local service and must remain bound to loopback. Do not expose it through a public proxy. Downloads contain sequence data. Uploaded temporary files are deleted after jobs; session results remain in memory until cleanup/shutdown. There is no telemetry.

Report vulnerabilities through the hosting repository's private security-report mechanism once configured. Do not include private genomic data in reports. No public security contact or hosted repository is configured yet. The initial 0.1.x series has no long-term security-support commitment.
